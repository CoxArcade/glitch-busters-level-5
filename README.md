# QuestForge / CoxArcade — Glitch Busters Level 5: Neon Fracture

A full playable browser-based Pygame game for mixed 6th–8th grade Python Pixel Playground.

## Five new stages
Skyline Zero, The Flooded Dataworks, Gravity Gardens, The Clockwork Bazaar, The Neon Singularity.

## Learning
All interactive code questions require **typing complete Python code** (including mentor checks, repair stations, five-stage code gauntlets, guardian hacks, and hidden vault seals).

**CTRL + ENTER** tests code; ENTER inserts a line; TAB inserts four spaces; ESC exits a code editor. Wrong code shows a worked explanation and requires another completed challenge before retrying. Code is compared by Python syntax tree, so equivalent spacing and quote styles are accepted.

## Controls
WASD / arrows: move. E: interact and hack. Z: sword. C: bow (starts unlocked). B: bombs (starts with five). X: dash. V: Overdrive. H: potion. J: journal. R: mission report. M: toggle music.

## Secrets
Ten hidden chambers contain ten distinct named bosses with unique health scaling and projectile patterns. Defeat the boss and guards, then type the Python vault seal to collect the treasure.

## Deploy
Create a new GitHub repository `glitch-busters-level-5`. Extract this ZIP and upload the **contents of this folder** to the repository root. If `.github` is hidden in your upload dialog, create `.github/workflows/deploy.yml` directly in GitHub and paste its contents. In Settings > Pages, choose GitHub Actions. The workflow installs pygbag and deploys the game.

Expected URL: `https://coxarcade.github.io/glitch-busters-level-5/`
